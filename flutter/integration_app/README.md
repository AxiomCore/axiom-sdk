# Axiom Flutter fixture integration app

A Flutter app (android, ios, macos, web) that runs named smoke checks of `axiom_flutter`
against the fixture backend in `../fixtures/backend`. It depends on `../axiom_flutter` and
`../axiom_flutter_generator` by path. The client in `lib/axiom_generated/` was generated by
`axiom pull` and is committed.

## Output

On start the app runs every check in `lib/checks/all.dart`, shows a list (name, pass/fail/skip,
message) and prints to the console:

```
AXIOM_CHECK <name> PASS|FAIL|SKIP <message>
AXIOM_RECEIPT {"platform":...,"baseUrl":...,"pass":N,"fail":N,"skip":N,"checks":[...]}
```

Grep device logs for `AXIOM_CHECK` / `AXIOM_RECEIPT` on any platform.

Checks for API that the SDK does not have yet exist and report `SKIP pending: <unit> (...)`.

## Run

Start the backend first: `../fixtures/backend/run.sh` (127.0.0.1:8791).

| Target | Command |
| --- | --- |
| Web (headless Chrome, writes `receipt-web.json`) | `tool/run_web.sh` (`SKIP_BUILD=1` to reuse `build/web`) |
| macOS | `flutter run -d macos` |
| iOS simulator | `flutter run -d <sim>` |
| Android emulator | `flutter run -d emulator-5554 --dart-define=FIXTURE_BASE_URL=http://10.0.2.2:8791` |

The base URL comes from `--dart-define=FIXTURE_BASE_URL=...` (default `http://127.0.0.1:8791`).
For a physical device, run the backend on a reachable address (`run.sh` binds 127.0.0.1; edit
`--host` there) and pass that URL.

Platform setup already done: macOS `com.apple.security.network.client` in both entitlements,
macOS 11.0 and iOS 13.0 deployment targets (Podfiles and `project.pbxproj`),
`NSAllowsLocalNetworking` for plain HTTP to localhost, Android `INTERNET` permission and
cleartext traffic in the debug manifest.

## Regenerate the client

```bash
AXIOM=~/bin/axiom tool/regen.sh
```

Builds `../fixtures/backend/main.acore` and runs `axiom pull --framework flutter --name fixture
--out lib/axiom_generated`, which runs `axiom_flutter_generator` from the local path dependency.

## Add a check

Add a `CheckDef('<area>.<name>', '<feature>', (ctx) async { ... })` to a list in
`lib/checks/*.dart`. Use `data(query)`, `failure(query)`, `expectEq`, `expectThat`, and
`skip('pending: <unit>')` from `lib/checks/ctx.dart`.
